# lab-seguridad-mttd-mttr-DA
Laboratorio práctico sobre desarrollo seguro y gestión de incidentes. Aborda validación y saneamiento de entradas, consultas parametrizadas, mitigación de riesgos OWASP, almacenamiento seguro de contraseñas y registro de auditoría. Incluye simulación de incidentes para evaluar la eficacia defensiva mediante las métricas MTTD y MTTR.
